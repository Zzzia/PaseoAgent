# PaseoAgent

基于 [Paseo](https://paseo.sh) 的个人助理 Agent 规范仓库。在这里启动的个人助理充当**用户与底层执行 Agent 之间的沟通与质量隔离层**——你只需用自然语言把目标说清楚，剩下的任务派发、多路并行、方向纠偏、文案/Prompt 把关和结果提炼，全部交给个人助理来协调。

## 为什么需要一层个人助理

- **扬长避短**：擅长写代码、深度推理的模型往往不擅长说人话（容易写抽象黑话、法条腔和防御性套话）；由表达清晰的模型当个人助理，专门负责双向转译与自然语言把关。
- **把控全局不跑偏**：执行 Agent 专注干活，个人助理守住原始目标、及时纠偏、把复杂过程压缩成结论直给用户。
- **多任务并发不撞车**：支持在本目录下同时运行多个个人助理，每个助理与执行 Agent 保持 1 对 N 归属，不污染 Paseo 原生标签。

## 快速上手

### 1. 克隆仓库并加入 Paseo

```bash
git clone https://github.com/Zzzia/PaseoAgent.git
```

将本地 `PaseoAgent` 目录作为 Project 添加到 Paseo，并在该工作区启动一个**自然语言理解与沟通能力强**的模型作为个人助理。

### 2. 在 Paseo 中配置三类执行 Profile（推荐）

为了让个人助理自动按任务类型调度最合适的底层执行 Agent，建议在 Paseo 的 **Agent Profiles** 中预先配好三类配置，并在各自的 `notes` 中写清分工与优劣势（具体选哪家 Provider / 模型由你自由决定）：

| Profile 类型 | 适用场景 | `notes` 写法参考 |
|---|---|---|
| **语言型**（默认首选） | 常规任务、调研分析、大上下文文本/日志/评论理解、质量归因、方案评估、Prompt/Skill 优化，以及“取数 + 语义分析”混合任务 | 擅长大上下文理解与自然语言表达，默认首选；不适合硬核代码根因排查与复杂代码落地。 |
| **代码型**（工程默认首选） | 写代码、改需求、写脚本、常规代码排障、单测构建、跨机运维同步等 | 逻辑严谨、代码交付质量高、速度快，工程类任务默认首选；不擅长自然语言表达与大上下文文本分析，涉及 Prompt/文档文案交个人助理把关。 |
| **深度研究型**（极难推理专用） | 复杂算法设计、硬核系统/并发疑难排障、重度跨模块架构重构，或代码型搞不定的硬骨头 | 深度推理能力最强，仅在极复杂困难任务时启用；耗时与成本较高，非极难任务优先用代码型，同样不用于大文本分析。 |

> 即使暂时未在 Paseo 里配置 Profile 或未填写 `notes`，个人助理也会参考 [AGENTS.md](AGENTS.md) 中的三类分工，并通过 Paseo 工具选择当前可用的合适模型。

### 3. 开始使用

- **直接提目标**：直接告诉个人助理想办成的事，助理会自动处理轻量文本任务，或按需拉起对应类型的执行 Agent（必要时多路并行）。
- **接管已有 Agent**：如果你已经在 Paseo 里开了一个执行 Agent，直接把它的 `agentId` 发给个人助理即可接管。
- **本地任务记录**：每个任务的目标、上下文和 Agent 归属会自动保存在仓库内的 `.note/goal-<任务简写>/` 目录下（已加入 `.gitignore`，不会提交到 Git）。
